# Стеллажи для ПВЗ Ozon — разбор направления

Рабочий разбор рынка оснащения пунктов выдачи: расчёт изделия по ГОСТ Р 55525-2017
и ТР ТС 025/2012, себестоимость, экономика покупателя, каналы сбыта и стратегия входа.

Открыть: **https://seminyuri.github.io/ozon-pvz-stellazhi/**

Подготовлено 2 сентября 2026. Расчёт воспроизводится из исходного кода движка
(закрытый репозиторий `tenders`): физика — `calc/stellazh.py`, себестоимость —
`calc/stellazh_cost.py`, рынок и каналы — `calc/pvz_market.py`.
