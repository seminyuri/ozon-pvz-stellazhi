# Стеллажи для ПВЗ Ozon — разбор направления

https://seminyuri.github.io/ozon-pvz-stellazhi/

Расчёт изделия по ГОСТ Р 55525-2017 и ТР ТС 025/2012, рынок, каналы, экономика
и стратегия входа. Одна страница, читается с телефона.

## Шрифты

Лежат рядом со страницей, а не берутся с Google Fonts. Причина — знак рубля:
у Google U+20BD входит в набор latin-ext, и на русской странице про деньги он
тянет этот набор для каждого начертания. На этой странице выходило 102 КБ из
373 — ради одного символа.

Нарезаны под страницу (кириллица, латиница, ₽, математика): 56 КБ вместо 373.
Пересобираются скриптом `tools/fonts/subset.py` в рабочем репозитории, покрытие
символов стережёт `tools/fonts/check.py`.

Все шрифты под SIL Open Font License — `fonts/OFL.txt`.
